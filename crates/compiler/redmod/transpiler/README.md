# redscript-redmod-transpiler

Strict community REDscript → REDmod source transpilation. Bodies come from shared typed
IR; retained source supplies declaration order, imports, docs and annotations.
Unsupported input returns diagnostics, never partial output.

## API conventions

- Use `analyze_sources`, then `transpile_selected`, or the combined `transpile_sources`.
  All input files are analyzed as community sources; only selected `FileId`s are
  emitted. Supply boot/engine dependencies explicitly and do not select them.
- Low-level `transpile` accepts `TranspileModule` bindings from structural
  `DeclarationPath`s to `ResolvedDeclaration`s. Retained AST, bindings, IR and
  symbols must come from the same successful compilation.
- Never associate bodies by spans, pointer identity or overload position.
  Automatic association uses resolved names/types/signatures and rejects inferred
  signatures, conditional declarations and multiple wrappers when ownership is
  unprovable. Explicit bindings are a caller contract, not proof that an unrelated
  same-name body belongs to a declaration.
- Inactive variants need separate analysis and actual bodies; the single-unit API
  does not synthesize them. Duplicate identities and competing replacements fail,
  including replacements in unselected dependencies.
- Diagnostics retain declaration paths and source spans; `display(&sources)`
  renders `REDMOD_TRANSPILE` excerpts. Generated byte mappings can overlap for nested
  statements. The core transpilation API performs no filesystem operations.

## Supported subset

Explicit typed signatures/locals, ordinary calls/operators/casts, structured IR
control flow, lowered for-in/interpolation, selected dynamic-array intrinsics,
verified primitive/reference defaults, overrides and uniquely associated patches.
Local names are hygienic by IR identity. Hoisting declarations does not move
initializer execution or repeated default resets. Callback return expressions
execute into discard locals; calls relying on callback results are rejected.
Every intrinsic is classified explicitly rather than emitted as an ordinary call.

### Literal conventions

Emit decoded values, not community escape spellings. Official String/CName
backslashes are raw: `\u{22}` is text, not an escaped quote. Strings use double
quotes; CNames use the verified single-quote form. LF multiline values are supported;
embedded delimiters, NUL and unverified controls fail with typed `LiteralError`s.
Resource/Tweak literals reject unverified backslash/multiline forms.

Finite Float values use round-tripping plain decimal spelling with a decimal
point and signed zero. Unsupported integer ranges, nonfinite values and Doubles
not exactly representable by the supported Float-cast path fail rather than narrow.
Native parser acceptance alone does not establish transpiler numeric support.

## Remaining work

| Gap | Approach |
| --- | --- |
| Inferred signatures, conditions, multiple wrappers and cross-module patches | Add finalized source identity facts and a variant-aware transpilation plan |
| Array prefixes crossing lazy branches, switch matchers or prior operands | Preserve execution-site prerequisites in shared lowering before relaxing source guards |
| Unsafe receivers, temporary/nonlocal places and strong/weak coercions | Add context-aware place/reference lowering; never mutate a copy as a substitute |
| Struct/enum/Variant/fixed-array default resets | Verify target initialization and repeated-reset behavior |
| Array count/grow/sort, `LongIntEnum`, variant inspection, `NameOf`, more `ToString`/`IsDefined` types | Add resolved typed mappings and official fixtures per operation |
| `editable`, `instanceeditable`, `inlined`, `replicated`, `testonly` transpilation | Preserve verified declaration semantics rather than dropping flags |
| Exact/select imports, unknown metadata, global replacements and broader conditions | Extend declaration/target planning without widening imports or guessing ownership |
| Wider integer/Double ranges and literal controls | Establish exact official constant-pool values before accepting new spellings |

Custom generics, lambdas/captures/function values, `mixedRef` and `neverRef`
class-value emulation have no fallback. Assets/tweaks conversion, system-lookup
rewriting and runtime patch workarounds are outside the current transpiler.

## Packaging and official validation

`package::publish_mod` stages authored scripts, optionally validates them, then
renames the inner mod into place. It rejects unsafe/colliding paths and existing
destinations; failure removes staging. Publication is atomic for visibility, not
crash durability. A cooperating-publisher lock does not protect against unrelated
processes creating the destination. `package::source_at` resolves generated byte
offsets to retained source mappings.

`validate::OfficialValidator { executable, timeout }` runs an explicitly trusted
absolute executable with bounded execution and file-backed logs. Success requires
exit success, the final commandlet success marker and fresh nonempty compiled/hash
artifacts; old caches are not reused. The tool has normal local access and may
write logs beside its executable. Use `validate_with_root` or
`publish_mod_with_root` when base-game blobs require an explicit absolute root.
The CLI exposes this through `transpile-redmod`, `--redmod` and `--game-root`.

## Tests

```sh
cargo test -p redscript-redmod-transpiler --locked
cargo test -p redscript-redmod-transpiler --all-features --locked
cargo clippy -p redscript-redmod-transpiler --all-targets --locked -- -D warnings
```

Use authored emitted-source/diagnostic snapshots; direct assertions cover values,
identity and provenance. Default tests require no installation. Set `REDMOD_EXE`
and `REDMOD_GAME_ROOT` to a trusted local installation to run:

```sh
cargo test -p redscript-redmod-transpiler --locked --test official -- --ignored --nocapture
```

The official test uses a 60-second bound per invocation and retains artifacts
under `target/redmod-official/integration-<pid>`. It checks mod identity, fresh
compilation, cache-reuse rejection and decoded String/CName pools. It does not
install fixtures into the game.

### Local official evidence (2026-10-29)

Five authored fixtures (Arithmetic, Arrays, Floats, Objects and literal values)
passed local official compiler v1.2.2; Floats produced three constexpr warnings.
String/CName pool checks confirmed raw backslashes and LF content. This evidence
is limited to those fixtures, was not rerun after upstream integration, and does
not establish wrapper/cross-module behavior or game-runtime compatibility.
