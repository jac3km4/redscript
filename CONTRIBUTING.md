# Contributing

## Validation

Use stable Rust for builds, tests, and Clippy. CI checks both default and all
features. Use the pinned nightly rustfmt to honor the repository's formatting
configuration:

```sh
cargo test --workspace --locked
cargo test --workspace --all-features --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo clippy --workspace --all-features --all-targets --locked -- -D warnings
rustup toolchain install nightly-2026-10-15 --profile minimal --component rustfmt
cargo +nightly-2026-10-15 fmt --all -- --check
```

Also check affected packages independently (for example,
`cargo check -p scc-core --locked`). Workspace feature unification can hide missing
dependency features in standalone builds.

## Regression tests

- Frontend diagnostics: `crates/compiler/frontend/tests/data/`.
- Generated bytecode: `crates/compiler/backend/tests/data/`.
- Formatter and code-edit behavior: each crate's `tests/data/`.
- Binary decoding and serialization: unit tests in `crates/io`.
- Output preservation on compilation failure: compiler API tests.
- C boundary behavior: C API tests.

Fixture tests use Insta snapshots. Review snapshot changes for correctness rather
than accepting them blindly. Bytecode snapshots do not verify game-runtime behavior.

## Correctness rules

- Every assembly error must prevent saving output, even without a source span.
- Lowering must preserve evaluation order and lazy evaluation. Keep generated
  initialization at the expression's execution point, including on loop back edges.
- Switches change the break target, but must preserve the enclosing loop's continue
  target.
- Treat malformed bundles as decoding errors: check indices, ranges, and address
  arithmetic rather than panicking. Decoding iterators must terminate after errors.
- Reject unrepresentable strings: prefixed lengths are limited to `u16` bytes, and
  NUL-delimited pooled strings cannot contain embedded NULs.
- Collection mutation guards synchronize serialization presence flags when dropped.
- Release builds abort on panic. C API ownership, borrowed lifetimes, and buffer
  contracts are documented in `crates/scc/capi/include/scc.h`; keep those contracts
  and the Rust API documentation consistent.

## Commits

Use lowercase Conventional Commit subjects, such as
`fix(io): reject oversized strings`. Keep independent fixes in separate commits.
